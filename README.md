# Edison Brinosa – Portfolio

1. Open this folder in VS Code (File > Open Folder).
2. Your photo is already at `assets/images/photo.jpg` (a portrait with space on the left works best).
3. Your contact links are in `index.html` (section 09). Gallery images are in `assets/images/works/`; new ones go in the `.collage` block (section 08).
4. Right-click `index.html` > Open with Live Server (install the "Live Server" extension), or just double-click `index.html`.

Files: `index.html`, `css/style.css`, `js/script.js`, `assets/textures/` (your 4 textures).
